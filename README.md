# MAX CARD FINANCE PRO V5 — SIGNATURE

## التثبيت
1. فك ضغط ZIP وارفع جميع الملفات مباشرة إلى جذر مستودع GitHub (لا ترفع مجلد الحزمة بحد ذاته).
2. Settings → Pages → Deploy from a branch → main / root → Save.
3. افتح رابط HTTPS وتأكد أن العنوان V5. إذا كنت تحدّث V4، صدّر نسخة JSON أولاً، ثم ارفع الملفات على نفس الرابط، ومن نفس المتصفح. لا تمسح تخزين الموقع. مفتاح تخزين V4 محفوظ.

## المميزات
- 16 صفحة تنقل، قائمة جانبية أو شريط سفلي، مركز القيادة، تايم لاين، تعليمات قابلة للبحث، إشعارات، 17 مجموعة إعدادات.
- نظام الجرد: فترات يدوية، أرصدة فعلية جديدة لكل محفظة والموقع لكل فترة، تسوية موثقة، إغلاق وأرشفة وترحيل رأس المال والديون. جميع الأرقام مدخلة يدوياً؛ لا اتصال بموقع المتجر.
- المبيعات والمشتريات، الإيداعات بالنسب والصرف، الرواتب، الديون للموقع وعليه، المصاريف، الحركات الرأسمالية، تحويل المحافظ، تقارير الفترة وتحليل أرشيفي. الهدف الشهري مؤشر مستقل في لوحة التحكم.
- العملة الأساسية USD؛ الديون للموقع بالـ USD أو SYP، الديون على الموقع USD، التحصيل لا يُعد ربحاً والتسديد لا يُعد مصروفاً.
- التخصيص: ألوان وخطوط وعمق وظلال وشفافية وحركة ووضع أداء ومفضلة وترتيب وإخفاء اختصارات ومؤشرات، اختيار صفحة البداية، استيراد وتصدير إعدادات. نافذة المراقبة الثانوية تعرض ملخصاً مباشراً للقراءة فقط، ويمكن الانتقال للقسم للتحرير؛ ليست محررين مستقلين متزامنين.
- التايم لاين مبني على ترتيب التاريخ ثم ترتيب التسجيل في اليوم الواحد. التحليلات قواعد حسابية محلية لا ذكاء اصطناعي خارجي؛ تقييم الصحة المالية استرشادي.
- الإشعارات المحلية، تثبيت، سجل، قراءة، صوت اختياري، تذكير يومي أثناء التشغيل. لا إشعار مضمون إذا أغلق التطبيق أو منع المتصفح الصوت. اختصارات قابلة للتخصيص؛ بعض اختصارات المتصفح محجوزة.
- حفظ محلي وتصدير واستعادة JSON، تشفير AES-GCM 256 مع PBKDF2 SHA-256 عند تفعيل رمز، استعادة مسودات، نسخة قبل آخر إغلاق وفحص بنية البيانات، تنبيه تعارض التبويبات. الحفظ المشفر غير متزامن؛ انتظر علامة الحفظ قبل الإغلاق. لا ضمان لحفظ المسودة عند إغلاق مفاجئ. احتفظ بنسخة خارجية دورية؛ حذف بيانات المتصفح أو فقدان الرمز قد يفقد البيانات. لا مزامنة سحابية. وضع الخصوصية إخفاء بصري وليس تشفيراً.
- التقارير PDF بواسطة طباعة المتصفح وCSV متوافق مع Excel؛ لا توليد XLSX أصلي. PWA عبر HTTPS بعد تحميل ملفات الخدمة. معدل الإطارات الفعلي يعتمد على الشاشة والجهاز. أيقونة MC بديلة، لأن الشعار الرسمي الأصلي غير مرفق. لا رسوم تشغيل خاصة بالتطبيق، وفق حدود GitHub Pages.

## الاختبار المنجز
فحص JavaScript باستخدام Node، واختبار الواجهة في Chromium باستخدام HTML مضمّن وتخزين محاكى بسبب حظر فتح HTTP المحلي في بيئة الاختبار. نجحت اختبارات 17 مجموعة إعدادات، حفظ حجم الخط، إنشاء الفترة، ربح المبيعات 50$، فرق صرف الإيداع 7.575757$، صافي سحب الرواتب 37$، مصروف 12$، تحصيل دين 100$، التايم لاين، مركز القيادة، نافذة المراقبة، أرصدة الجرد، الإغلاق والتسوية والترحيل إلى 330$، حفظ الأرشيف والإعدادات، وعدم وجود تجاوز أفقي على عرض 390px. لا أخطاء JavaScript أثناء السيناريو. لم يُختبر النشر الفعلي أو كل الخيارات والأجهزة أو العمل دون إنترنت أو دورة التشفير والاستعادة على V5. اختبر دورة مالية ببيانات وهمية قبل العمل الفعلي.
